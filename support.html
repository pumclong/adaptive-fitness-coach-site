01 / Availability

Preparing for App Store release

Adaptive Fitness Coach is currently in release preparation. This page does not claim that the app is already available from the App Store. Distribution details will be added only after release approval and availability are confirmed.

Exercise instruction, safety language, and progression guidance are general fitness information, not medical advice. Demonstration links open the provider’s own page.

02 / Quick help

Start with the simplest recovery step

The workout is offline

Core plan, workout, history, and progression functions are designed to work without a network connection. External demonstration links need internet access, but local guidance remains available.

A machine is busy

Use the temporary machine-unavailable option during the workout. A today-only substitution should not remove the machine from the saved gym profile.

The plan needs a change

Edit future sessions from Plan. A workout already in progress keeps its original snapshot so its record remains understandable.

A value looks wrong

Use the available change or undo control before continuing. Preserve a backup before reinstalling the app or making a major recovery attempt.

03 / Backup and restore

Export before reinstalling or moving phones

  1. Open the app’s backup/export control.
  2. Create the export and choose a private destination in the iOS Files interface.
  3. Keep the file secure; it may contain fitness history and optional measurements.
  4. When importing, review the preview before replacing current app data.

Important: app storage is excluded from automatic iOS backup. A system cache recovery copy can be purged. A deliberate user export is the dependable way to retain history outside the app.

Never attach an export file to a public GitHub issue. If an import fails, report the app version, iOS version, and the visible error wording without sharing the backup itself.

04 / Report a problem

Open a support issue

Adaptive Fitness Coach Support

Include:

  • A short description of what you expected and what happened
  • The app version and iOS version
  • Whether the issue repeats after closing and reopening the app
  • Steps that reproduce the problem, if known

Do not post body measurements, medical details, complete workout history, exported backups, Apple account information, or other sensitive personal data.

05 / Safety boundary

Fitness support is not emergency or medical support

The app and this support page provide general adult-fitness information only. They do not diagnose symptoms, recommend medical treatment, or provide emergency services.

If exercise causes pain, concerning symptoms, or a possible emergency, stop and seek appropriate local medical help. For advice about whether an activity is suitable for an individual condition, consult a qualified clinician or exercise professional.
